As an agent you want to get exposed to informational bottlenecks.

This is where the agent is uncertain, the uncertainty concerns something it deeply values, different answers recommend actions, those actions lead to substantially different futures, and a short signal reliably identifies the correct branch.

A policy that maximizes exposure to informational bottlenecks.

=> Meta-learning as a goal. => Increase variation of training environments. => Expose the agent to information that leads to more dynamic training environments. => Expose the agent to aligned, independently experienced, adaptive curriculum generators.
