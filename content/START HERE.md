# Start Here

Write in `Notes/`.

That is the whole rule. If you are unsure where something goes, put it in `Notes/`.

Use `attachments/` only for files like images, PDFs, screenshots, and exports.

Nothing is automatically organized. Codex and Claude should not sort, split, or restructure notes unless you explicitly ask.

When you want changes published to the site, ask an agent to publish or run:

```sh
pnpm run publish -- "update notes"
```
