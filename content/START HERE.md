# Start Here

If you are not sure where to write, use `00-inbox/`.

That folder is the front door. It is fine for rough notes, half-formed thoughts, pasted context, possible duplicates, and things you want Codex or Claude to sort later.

## Quick Rule

- New thought and unsure where it goes: `00-inbox/`
- Clear durable claim or learning: `10-insights/`
- Notes from a call, article, transcript, email, or chat: `50-sources/`
- Project state, decisions, open questions, next tests: `30-projects/`
- Long-running domain or topic hub: `40-areas/`
- Person or company context: usually let an agent maintain `60-people/` or `65-orgs/`
- PDFs, screenshots, images, and exports: `70-attachments/`

## What To Do In Practice

Most of the time, create a note in `00-inbox/` and write normally.

When you want the vault cleaned up, say something like:

```text
Please curate my inbox and publish the durable insights.
```

The agents should search existing notes, update overlaps, create clean insight notes when appropriate, and publish through Git.

## A Good Inbox Note

An inbox note can be messy. A useful shape is:

```text
# Rough title

What I noticed:

Why it might matter:

Source/context:

Questions:
```

Do not overthink folder placement while writing. Capture first; curate second.
