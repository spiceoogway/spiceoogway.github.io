# Home

This is a local-first Obsidian vault, Git-backed insight store, and public Quartz site.

The vault is insight-first: durable claims, learnings, decisions, reusable patterns, and open questions are the primary notes.

If you are not sure where something belongs, start with [[START HERE]].

## Vault Structure

- `00-inbox/` for hunches and unresolved captures
- `10-insights/` for atomic durable claim notes
- `20-syntheses/` for multi-claim summaries
- `30-projects/` for active project hubs
- `40-areas/` for long-running domain hubs
- `50-sources/` for raw source captures
- `60-people/` for sparse person hubs
- `65-orgs/` for sparse organization hubs
- `70-attachments/` for files and media
- `90-meta/` for templates and vault instructions

Publishing is handled with `pnpm run publish -- "<message>"`.
